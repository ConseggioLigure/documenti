# Documenti liguri

The complete local collection covers 72,743 entries, 146,658 excerpts and 2,670 full pages from Casaccia (1876), Olivieri (1851), Frisoni (1910), Paganini (1857), PFB (1873) and Penzig (1897). The transcriptions and canonical source geometry remain in LigurianKB; this repository serves static PNGs without live cropping. Historical spelling is preserved and is not a model for modern Genoese. A successful local refresh does not establish that new image URLs have been published.

Pages are in `<document>/pagine/<source-page>.png`; source page IDs are not always printed pagination. Plates use `tavola-<number>.png` (the first table number for a shared face); other unregistered pages use `<source-PDF-name>-<PDF-page>.png`. Excerpts are in `<document>/<section>/<first-headword>.<index>/<number>.png`. IDs use NFC lowercase; a single trailing `-` distinguishes uppercase entries that would otherwise collide. Sections use the source's root section, so Paganini's thematic sections are filed under `main_dictionary`.

## Bibliography

- Giovanni Casaccia, *Dizionario genovese-italiano, seconda edizione, accresciuta del doppio e quasi tutta rifatta*. Genova: Tipografia di Gaetano Schenone, 1876.
- Giuseppe Olivieri, *Dizionario genovese-italiano*. Genova: Giovanni Ferrando, 1851.
- Gaetano Frisoni, *Dizionario moderno genovese-italiano e italiano-genovese*. Genova: A. Donath, 1910.
- Angelo Paganini, *Vocabolario domestico genovese-italiano con un’appendice zoologica*. Genova: Tipografia di Gaetano Schenone successore Frugoni, 1857. The pilot includes table I, figures 1 and 17.
- P. F. B., *Vocabolario tascabile genovese-italiano per il popolo*. Genova: co’ tipi del R. I. Sordo-Muti, 1873. The dictionary occupies printed 17–303 and the personal/place-name repertory 304–314. Shared circumflexes over `ou` and `eu` are transcribed `ôu` and `êu`.
- O. A. J. Penzig, *Flora popolare liigure. Primo contriuto allo studio dei nomi volgari delle piante in Liguria*. Tip. di A. Ciminago, 1897. Both separately printed directions share the scan document `penzig-1897`; all 112 native RGB pages and 2,750 article excerpts retain their supplied pixels.

## Preparation

With Pillow installed and sibling `LigurianKB` and `LigurianScans` checkouts present, run `python3 build.py` for the fixed pilot or `python3 build.py --all` for every cataloged work with prepared scans. `LigurianKB/exports/manifest.json` supplies each document ID, filename, content key, entry count and snapshot hash; the VPL volumes remain excluded until their scans are prepared. Preparation is offline; no PDFs, image downloads or server are needed. The builder validates IDs against the complete exports, checks prepared source hashes, copies full pages byte for byte and checks every crop's bounds, complete decoded pixels, mode and 300 DPI metadata. Valid existing PNGs retain their exact bytes. Existing deskew and rotation are already applied; the builder changes neither. Binary text and continuous-tone illustrations, covers and notices are preserved.

Use `--all --book penzig-1897` to generate only Penzig and retain the other completed books; `--book` is repeatable. `--scans /path/to/LigurianScans` and `--exports /path/to/LigurianKB/exports` select explicit input checkouts. A bounded build requires an existing complete output manifest and frozen mappings. If the scan manifest changed, pass its previous pinned version with `--previous-scans-manifest /path/to/previous/manifest.json`. Before preserving an unselected book, the builder checks its unchanged scan registration, mapping hash, complete canonical ID set, every source-location pointer, printed locator and pixel box against the current export. Later spelling edits may leave the frozen mapping's labels and image paths unchanged; the private producer manifest records the compatibility proof, the frozen generating export hashes and current compatible export pins, carrying the generating hashes forward on later runs. Only the selected document's obsolete PNGs are removed after successful validation. The public pilot is not rewritten.

Penzig combines `penzig-species.jsonl` and `penzig-ligurian.jsonl` before validating heading/index paths, retaining every canonical source ID. Native page PNGs are copied byte for byte, including their supplied 96.012 DPI metadata; their physical PDF scale is approximately 300 DPI. Article crops use the same native RGB pixels and new 300 DPI metadata, without resampling, rotation, tonal changes or thresholding.

The full run writes ignored producer mappings to `exports/<document>.images.jsonl`, with source IDs, original location pointers, page/column locators and numbered images; `exports/manifest.json` pins inputs and mapping hashes. Consumers must require `complete: true`. Mappings publish only after every book succeeds; obsolete PNGs in the generated document folders are removed then. Paganini’s illustration catalog retains its private working-snapshot pin and separately pins the current public dictionary, preserving every illustration binding and region. The public [pilot.json](pilot.json) remains the ten-entry example. The collection exceeds GitHub Pages’ 1 GB site limit; URLs use GitHub raw hosting.

Source export, scan manifest, illustration catalog and delivery-map hashes are pinned in `pilot.json`, alongside exact location pointers and page/column associations. On 23 October 2026, thirteen images covering the ten-entry pilot rendered in Chat (GPT-5.6 Sol) and Work (GPT-6.1 Sol). After full publication, 42 PNG URL checks passed, including trailing-hyphen IDs, question-mark headwords and errata. Fresh plugin queries without supplied URLs retrieved and rendered Paganini text and its illustration in Chat, and both Frisoni capitalization cases plus Paganini's two-part erratum in Work. These are representative host checks; local verification covered every crop's pixels, mode, DPI and source geometry, every full-page hash and all runtime text and locators.
